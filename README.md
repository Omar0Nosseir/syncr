# Syncr — interactive front-end

Open `index.html` in a modern browser.

## Included
- TikTok-style full-screen vertical FYP with snap scrolling/swiping
- Functional opportunity search across the opportunity library + filters
- Opportunity images, details, saving and real application form
- Application tracking with submitted status and timeline
- Editable talent profile saved in localStorage
- AI opportunity assistant with typed chat
- Browser voice chat using Web Speech API when supported
- Light theme by default + purple dark theme toggle
- Responsive desktop/tablet/mobile layout
- Data persistence with localStorage

## Important
This is a browser-only prototype. The application workflow, AI answers and opportunity library are simulated locally. To make it production-real, connect the same UI to your .NET API/SQL database and a real AI/voice provider. Browser voice input depends on the user's browser permissions/support.

Opportunity artwork uses remote Unsplash image URLs, so an internet connection is needed for those images to load.
